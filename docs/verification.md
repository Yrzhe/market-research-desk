# Local verification

- `npm run check`: unit and integration checks for comparable alerts, missing and stale observations, immutable runs, local script collection, and webhook credential separation.
- `node --check public/app.js` and `node --check src/server.js`: syntax pass.
- `frontend-design` UI audit after the visual revision: sample overview, alerts, decisions, runs, configuration, and the unconfigured overview at 390px and 1440px. All six report 0 horizontal overflow, 0 contrast failures, 0 undersized targets, 0 emoji, 0 unnamed controls and 0 page or console errors. Light and dark screenshots were captured for each. A strict Content Security Policy blocks the audit script's inline keyboard probe; manual Tab showed a visible 2px outline.
- `taste-skill inspect --app` on the sample overview: 0 FAIL and 2 WARN. The dense read-only app uses 12px metadata and axis labels, producing a `tiny-text` warning; the chart and operations column have different natural heights, producing `ragged-row`. Both keep data legible without filling the operations panel with invented content. Geist also triggers the slop detector's generic `overused-font` warning; it is the repository's existing licensed UI font, retained for consistency.
- Chrome walkthrough after revision: overview market evidence, alert calculation and source, market filter both empty and populated, archived run evidence, decision details, theme switch, Escape dismissal and focus return all worked. Mobile and desktop screenshots were reviewed against the [prior baseline](screenshots/baseline/overview-desktop-sample.jpg).

Hosted authentication, live source coverage, Telegram delivery, VPS timers, and Cloudflare routing were not tested in this local repository build. The synthetic sample is fictional and explicitly labelled.
